# 🌸 Botanical Classification with Gaussian Naive Bayes

Implementation of probabilistic density estimation using Bayes' theorem with Gaussian likelihood assumptions on continuous features.


## 🔬 Engineering Workflow
1. **Feature Modeling:**
   * Multi-class problem evaluated across sepal and petal morphological measurements.
2. **Likelihood Computation:**
   * Fitting conditional Gaussian distributions per class via `GaussianNB`.
3. **Error Analysis:**
   * Plotted and visualized confusion matrix distributions using `seaborn` heatmaps.
